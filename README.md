## 1. 一句话总框架

卢麒元的核心不是单纯看多黄金、石油或某只股票，而是用“资本载体与价值中枢迁移”解释美元旧秩序松动、全球资本回流核心区、资产价格重定价和新货币锚形成的过程。

```text
美元旧锚松动（中国廉价商品 + 中东石油）
-> 黄金先表达美元信用折价
-> 金银铜油粮次第表达资源与必需品重定价
-> 中国若减少廉价初级工业品输出，全球化工、金属和能源成本可能重新定价
-> 日本/日元触发全球套息交易平仓与货币震荡
-> 霍尔木兹/中东成为能源通道和美元石油锚的反复博弈点
-> 资本向美国/日本等核心区回流并出现速冻
-> 向心坍缩
-> 美元重置与人民币“电力信用 + 战略资源备兑”复合
```
