# 中国海油与中曼石油近几日量价复盘

> 数据截止：2026-07-28 09:44（北京时间）。7月28日成交量、成交额和换手率均为早盘快照，不能与完整交易日直接等量比较。

## 1. 分析结论

1. **中国海油处于“地缘溢价回吐、基本面支撑尚在”的回撤阶段。** 7月23日收盘至7月28日09:44下跌约6.37%，而同期布伦特原油从7月23日结算价100.69美元/桶回落至约85.30美元/桶，跌幅约15.28%。中国海油明显强于油价，但暂未出现重新转强的确认。
2. **中曼石油已经从油价弹性交易切换为高波动风险定价。** 7月24日冲高回落、全天换手率20.80%，7月27日跌停，7月28日早盘换手率已达4.15%。这说明筹码仍在快速交换，不能把早盘从19.20元回升简单视为见底。
3. **两只股票不能只按油价涨跌比较。** 中国海油的核心变量是油价、产量、成本和分红；中曼还叠加上半年业绩预减、伊拉克钻机停工及勘探投入等公司特有风险，因此中曼的风险级别明显更高。
4. **长鑫科技上市不是这轮下跌的主要解释。** 7月27日A股主要指数上涨、约5200只股票上涨，而石油开采板块相对偏弱；资金虹吸可能放大局部波动，但油价地缘溢价回落和中曼自身风险更能解释两者走势。

## 7. 风险与反例

1. 中东局势可能再次升级，布伦特快速反弹，导致当前对“风险溢价回吐”的判断很快失效。
2. 中国海油虽然相对抗跌，但如果油价长期跌回更低区间，盈利和分红预期仍会被重新下调。
3. 中曼若迅速公告伊拉克钻机复工、产量超预期或获得重大订单，个股风险折价可能快速修复。
4. 7月28日仅为早盘数据，盘中换手率不能直接外推至全天；收盘价和尾盘资金方向可能改变短线判断。
5. 技术位置只能描述筹码和交易行为，不能替代公司现金流、产销量和地缘事件的基本面核验。

## 8. 后续观察清单

- **本周看中国海油：** 30.00至30.50元能否形成有效承接；若缩量企稳，可视为第一轮冲击消化，若放量跌破则需降低对短期强势的判断。
