# FOMC前停火与油价压制时间线复盘

## 1. 分析结论

1. 下一次FOMC会议为2026年9月15日至16日，决议对应北京时间9月17日凌晨2时；该次会议带经济预测和点阵图。
2. “每次议息前都停战压油价”不成立。2026年前五次会议中，1月没有相关战争，3月会议前冲突仍在升级；4月、6月和7月则都在会议前约一周内出现停火、延期或暂停打击消息。
3. 若只统计2月28日中东战争开始后的四次FOMC，3次出现会前缓和，样本命中率为3/4；若统计2026年前五次会议，则为3/5。样本很小，不能据此证明因果或预测9月一定重演。
4. 相关性有合理的政策动机解释：能源价格会影响通胀及利率预期，美国政府有压低汽油和通胀预期的动力；但FOMC日期早已预定，停火还受军事、外交和国内政治约束，现有公开证据不足以证明由美联储协调。
5. 更可交易的结论不是“议息前必停火”，而是：FOMC前若同时出现缓和消息、布伦特近月下跌、期限结构走弱、航运恢复和保险费下降，才说明风险溢价与实物流一起改善；只有口头消息而物流不变，油价下跌可能只是短期金融压价。

## 4. 逻辑链拆解

| 逻辑链 | 起点 | 传导过程 | 影响资产 | 最容易出错的环节 |
| --- | --- | --- | --- | --- |
| 停火消息链 | 暂停打击或谈判消息 | 断供概率下降 → 油价风险溢价回吐 → 通胀预期下降 | 原油、美债、美元、股票 | 把口头暂停当成永久和平 |
| 政策窗口链 | FOMC日期临近 | 油价下降 → 加息压力下降 → 风险资产估值压力缓解 | 科技股、债券、美元 | 把时间接近直接当成政策操纵证据 |
| 市场放大链 | FOMC日期已知 | 交易者提前调整利率押注 → 停火消息对油债股影响被放大 | 油、股、债 | 忽略市场自身抢跑 |
| 实物流验证链 | 停火落地 | 航运恢复、保费下降、装船增加 → 现货紧张缓解 | Brent期限结构、油运、油股 | 只看期货价格，不看物流和库存 |

| 美股成长股 | 通胀及加息担忧下降，估值受益 | Fed仍偏鹰、核心通胀黏性 | 2年期美债、纳指、美元 |
| 美债 | 油价下降有利于通胀预期回落 | 财政发债和核心通胀 | 2Y/10Y、盈亏平衡通胀率 |

| 只是金融压价 | Brent下跌但期限结构和库存仍紧 | 价格先跌，基本面没有同步转弱 | 期限结构转弱且库存累积 |
| 9月模式是否重演 | 9月8日至16日的外交消息和实物流 | 多项指标同时改善才算重演 | 只有谈判标题，没有执行 |

## 7. 风险与反例

1. 样本仅有五次会议，其中与战争相关的只有四次，统计意义非常有限。
2. FOMC会议日期提前公布，外交行为接近会议可能是市场关注放大，而非政策协调。
3. 美国政府、军方、外交系统和美联储不是同一个决策主体，不能把共同受通胀约束等同于共同操纵油价。
4. 3月会议前没有停火，反而是高油价进入议息讨论，证明该模式并非硬规则。
5. 即便9月会前再度出现停火消息，如果库存、船流和保险费没有改善，油价仍可能在消息消化后反弹。

## 8. 后续观察清单

- 当前会议：北京时间7月30日凌晨2时看利率声明，2时30分看发布会的能源通胀措辞。
- 下一次会议：2026年9月15日至16日；从9月8日起进入“会前一周观察窗”。
- 每次会前同时跟踪：外交消息、实际船流、战争险保费、Brent期限结构、EIA库存、2年期美债收益率。
- 如果再次出现“停火消息 + 油跌”，先判断是风险溢价回吐还是实物流恢复，不直接推导为长期油价转空。
