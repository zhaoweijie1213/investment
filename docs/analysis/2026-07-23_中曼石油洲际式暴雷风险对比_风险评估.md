# 中曼石油是否存在洲际油气式暴雷风险

## 1. 分析结论

1. 截至2026年7月23日，公开信息不足以把中曼石油定义为已经走上洲际油气2022年至2023年的债务危机路径。洲际当时已经出现23.74亿元逾期债务、流动负债超过流动资产38.97亿元、多笔债务无法兑付、账户和子公司股权被冻结、非标准审计意见及预重整；中曼目前尚未披露贷款或担保逾期、司法冻结、持续经营重大不确定性或非标准审计意见。
2. 中曼并非低风险。2026年一季度末资产负债率约63.99%，流动资产与流动负债几乎相等，货币资金18.84亿元低于短期借款与一年内到期非流动负债合计21.42亿元；一季度经营现金流转为-0.64亿元，存货、应收账款和在建工程均较年初上升。它属于融资和项目现金流不能明显恶化的扩张型资产负债表。
3. 当前更可能出现的不是毫无预兆的破产重整，而是盈利、现金流或套保结果低于市场预期造成的估值回撤。2026年半年归母净利润预计同比下降64.68%至70.46%，且截至6月16日已确认套保投资收益0.735亿元，主营利润质量、未平仓头寸和保证金占用仍需正式中报确认。
4. 综合判断：洲际式债务暴雷风险目前为低到中等，整体基本面与股价波动风险为中高。若后续出现逾期债务或担保、账户冻结、审计非标、经营现金流连续为负、境外债主要用于续短债、套保大额浮亏等组合信号，才应把风险等级上调到高。

## 4. 逻辑链拆解

| 逻辑链 | 起点 | 传导过程 | 影响资产 | 最容易出错的环节 |
| --- | --- | --- | --- | --- |
| 洲际式危机 | 到期债务无法偿付 | 逾期扩大 → 冻结 → 审计提示持续经营问题 → 债权人申请重整 | 股权与债权 | 把一般高负债误判为已经违约 |
| 中曼当前压力 | 海外扩张和油田资本开支 | 长债、担保和在建工程上升 → 依赖项目回款及银行续贷 | 中曼石油 | 只看货币资金，不看受限资金和到期结构 |
| 利润质量风险 | 产销差与套保收益 | 存货增加、销售兑现偏慢，套保支撑利润 → 主营现金回收弱于账面利润 | 利润与估值 | 把套保收益等同于可持续主营利润 |
| 海外运营风险 | 伊拉克井队停工或项目延期 | 工程收入下降 → 回款延后 → 子公司偿债压力经担保回到母公司 | 现金流与担保 | 把油价上涨等同于所有业务同步受益 |
| 控股股东质押 | 控股股东融资需求 | 股价下跌 → 补充质押或处置压力 → 治理和市场情绪恶化 | 股价 | 把股东个人质押直接等同于上市公司债务 |

## 7. 风险与反例

1. 无保留审计意见只能说明截至2025年末的公开财务报表不存在导致非标的重大问题，不能保证2026年海外经营、套保和回款不会快速变化。
2. 货币资金18.84亿元不等于全部可自由使用；若受限资金比例较高，实际短债覆盖率会低于账面计算。
3. 对全资子孙公司的担保不是表外第三方利益输送，但如果子公司项目失利，集团经济损失和母公司代偿责任仍然真实存在。
4. 高油价既能提高油气资源价值，也可能扩大未平仓卖出套保头寸的浮亏，并加剧海外冲突造成的停工风险。
5. 当前股价快速上涨反映的是油价和地缘事件预期，不代表资产负债表风险已经下降；基本面风险与短期股价方向可以暂时背离。
